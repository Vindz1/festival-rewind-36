Méthodologie de calcul des cotes

1. Base Argus : valeur médiane issue de l'historique des ventes mondiales Discogs.
2. Ajustement : le standard du marché est le Very Good Plus (VG+). Un Mint (M) vaut 150% de cette base, un Good (G) 40%, etc.
3. Règle d'or : le disque représente 70% de la cote, la pochette 30%. Le calcul croise ces deux pondérations.
4. Indice de confiance (●/●/● sous chaque cote) : indicateur heuristique, pas une probabilité statistique — Discogs ne fournit ni le nombre de ventes ayant servi à une suggestion de prix, ni le prix moyen des ventes récentes (visible sur le site, pas exposé par l'API). Basé principalement sur l'écart entre la cote et le prix le plus bas actuellement en vente sur cette release précise, ajusté par la liquidité du marché. Un point rouge signale une cote à vérifier manuellement sur Discogs plutôt qu'à prendre pour argent comptant.

⚠ disque(s) ont une cote basée sur un marché fin ou des données incertaines (point rouge, confiance < 40%). Ces valeurs pèsent dans le total mais méritent une vérification manuelle sur la page Discogs de la release concernée avant d'en tirer des conclusions.
